# Converter

A simple **Converter Application** designed to convert values between different units and formats. The project demonstrates basic programming concepts such as user input, calculations, functions, and conditional statements.

## Features

* Length conversion
* Weight conversion
* Temperature conversion
* Currency conversion
* Time conversion
* Area conversion
* Volume conversion
* Speed conversion
* User-friendly menu
* Input validation

## Conversion Categories

### Length

* Meters
* Kilometers
* Centimeters
* Miles
* Feet
* Inches

### Weight

* Kilograms
* Grams
* Pounds
* Ounces

### Temperature

* Celsius
* Fahrenheit
* Kelvin

### Time

* Seconds
* Minutes
* Hours
* Days

### Speed

* Kilometers per hour
* Meters per second
* Miles per hour
